# Project summary — draft, not submitted

Context Rollover Guard is a local-first Codex continuity and recovery runtime. Its primary safety constraint is that uncertain mutation acceptance never authorizes automatic replay. Native continuation remains the default; explicit migration requires a user choice, and unobservable tool/child activity preserves the source task.

The standard-library Python runtime separates capability discovery, continuation policy, immutable transaction/answer archives, local projected usage, quota snapshots, empirical estimates, and advice rendering. Recommendations never select a model on the user's behalf. Unknown telemetry and quota data remain unknown.

See [architecture and usage](../CONTRIBUTOR-QUICKSTART.md), [compatibility boundaries](../COMPATIBILITY.md), and [evidence inventory](EVIDENCE.md). These local changes have not been published as a release; current eligibility/program terms and application fields must be checked before submission.
